# 📋 Clipboard Responsive Landing Page

A fully responsive landing page for a clipboard management app that allows users to store and access copied text across all their devices.  
This project was built to practice modern CSS layout techniques and responsive web design principles.

---

## 🚀 Features

- **Responsive Design:** Adapts perfectly to desktop, tablet, and mobile screens using CSS media queries.  
- **Modern Layouts:** Combines **Flexbox** and **CSS Grid** for flexible and balanced section arrangements.  
- **Optimized Spacing:** Consistent use of **margin** and **padding** for clean, readable structure.  
- **Organized Components:** Includes hero header, feature highlights, workflow tools, partner logos, and footer.  
- **Stylish Buttons & Typography:** Custom button designs with hover effects and Google Fonts integration.  
- **Lightweight & Clean Code:** Built entirely with HTML and CSS—no frameworks required.

## 📱 Responsiveness

The design was optimized for multiple breakpoints:

1. **Desktop (≥1025px)** – Default wide layout with side-by-side content and multi-column grids.  
2. **Tablet (769px - 1024px)** – Reduced width, two-column grid layouts, and balanced scaling.  
3. **Mobile (≤768px)** – Stacked sections, centered text, full-width buttons, and simplified visuals.  
4. **Small Mobile (≤480px)** – Fine-tuned typography and spacing for very small screens.

## 🎨 Design Details

- The header section uses **Flexbox** for vertical centering and responsive button alignment.  
- Feature and logo sections use **CSS Grid** for evenly distributed layouts.  
- Consistent **padding and margin spacing** were applied to achieve clean white space.  
- Different **background images** are used for desktop and mobile layouts for better visual balance.  
- Smooth responsiveness between breakpoints ensures a seamless user experience.
